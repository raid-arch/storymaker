# 世界観・シリーズ・作品のツリー

「ストーリー管理」「世界観ライブラリ」の共通ツリーで、以下のように整理できる。

```
世界観
├ 単独作品
└ シリーズ
  ├ 作品
  └ 作品
```

世界観・シリーズの「＋」で作品を、その隣の「＋ シリーズ」でシリーズを追加する。名前や説明は鉛筆ボタンで編集する。所属変更ボタンで移動先の世界観・シリーズを選択する。シリーズを移動するとその中の作品も移動する。世界観・シリーズは折りたためる。サンプル作品を自動登録しない。

保存先の Project.collectionId は省略可能な文字列。従来の parentId は以前の参照の移行専用として維持する。collectionId は見た目の所属だけを表し、ほかのストーリーの人物・秘密・本文を継承させない。配置先の世界観は worldIds に追加し、既存の参照を削除しない。所属なしへの移動でも参照を保持する。旧データは最初に参照する世界観の下に表示し、保存内容を自動変更しない。

循環、自分自身・子孫への移動、通常作品を入れ物にする配置は拒否する。シリーズ／世界観の削除は中の作品を削除せず、直接の子の所属を外す。子を持つシリーズの種類変更は先に子の移動を案内する。過去履歴の所属先が削除済みなら所属なしとして復元する。

ボタンの高さ・文字サイズ・余白を共通化。アイコン操作も同じ基準のタップ範囲に揃え、長い文言は画面幅に応じて折り返す。
