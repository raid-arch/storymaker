# 制作画面（Android 1.0.5）

## 制作の流れ

ストーリー・世界観を一覧や切替メニューから開くと専用の制作画面になる。従来の管理画面も残り、サイドバーの「制作画面」または概要のボタンから行き来できる。最後に開いた制作対象とシーンを端末内に記憶し、続きから再開する。

### ストーリー

1. 「構成・執筆」で章を作り、シーンを作成する。章を決める前に未分類で書き始めてもよい。
2. 本文を直接書く。「広げて書く」で長文用の執筆画面に切り替える。本文・名前・進行状態・あらすじ・メモは自動保存される。
3. 同じ画面の「いつ・どこで」で、世界の事件、共通年、細かな時点・前後関係、舞台を指定する。事件を選んだとき、共通年が未記入なら資料の数値年代を初期値に使う。以後の編集は資料側に影響しない。
4. 人物の登場を選び、各シーンの状態・行動や関係の変化を書く。場所の変化もシーン単位で記録できる。
5. 足りない人物・場所・出来事は画面内で作成し、シーンへ接続する。初期保存先は作品専用。明示的に共有資料を選んだ場合だけ世界観側に追加する。
6. 「登場人物・関係」では人物を中心に役割・目的・状態・補足・自由項目と、血縁以外の関係も確認できる。世界観の人物関係は参照扱いで、この画面から削除しない。作品固有の関係を追加できる。
7. 「舞台・設定資料」で参照資料を読み、作品固有の状態・補足を追加する。元の設定の変更は「元の設定の詳細を開く」から明示的に行う。
8. 「シーンの時間軸」で、世界の事件に対する各シーンの時点・場所・人物を一覧し、執筆に戻る。章・シーン順、または共通年順を選べる。同年内の自由表記は自動計算せず、描く順番を使う。

「本文を書き出す」は章・シーンの順番で本文だけをMarkdownにする。基本設定・真相・役割・制作メモ・あらすじは含めない。全データの保護には従来のJSONバックアップを使う。旧プロットボードとシーンは共通データを使い、既存のシーンも「このシーンを執筆」で開ける。

### 世界観

国・街・村・人物・病気・症候群・歴史／戦争などの開始ボタンから、名前をつけて作成する。カテゴリは自由入力でき、独自の種類を増やせる。本文と自由項目を同じ画面で作成し、画像・リンク・各種詳細は既存の編集機能から設定する。詳細画面から戻ると直前の資料を再び開く。「この世界観を使うストーリーを作成」で制作を始められる。

## 互換性・保存

- 既存のversion 1／IndexedDBストアを継続する。サンプル投入、データ初期化、シーンの複製やID変更をしない。
- Sceneには省略可能な本文・時点表記・舞台・事件・登場人物・人物別の場面状態・舞台の場面状態・関係変化を追加する。以前のsummary／note／year／linksはそのまま保持する。
- Studioのportrayalsに、作品と設定を結ぶ固有情報を保存する。元のEntryを書き換えず、他作品と共有しない。旧データには空のリストを補う。
- シーン内の明示的な人物・場所・事件を既存のlinksにも反映し、影響範囲と検索でたどれる。本文と作品固有の設定は全文検索対象になる。公開情報モードは従来どおり専用に書いた公開文章だけを出力し、新しい本文・状態を自動公開しない。
- 設定を削除すると制作データの対応する参照も除去する。シーンを削除すると、そのシーンの本文も対象になるため確認を出す。章を削除してもシーンは未分類に残す。
- 最後の制作対象・編集対象は補助的な端末内設定。利用できない環境でも作品データのIndexedDB保存は継続する。

## 軽量化と検証

制作画面は遅延読み込みし、参照可能な設定一覧は人物・世界観が変わったときだけ作り直す。PCでは章と本文を左右に、狭い画面では縦に配置する。全文執筆モード、人物・資料検索、キーボード操作と通常のタップボタンを利用できる。

保存互換性、作品・シーン状態の独立、追加先の検証、削除時の参照整理、本文だけの出力を単体テストで確認する。ブラウザでは章・本文の作成、資料との接続、その場での人物追加、再読み込み、オフライン起動、関係の追加、世界観の村・病気・自由項目の作成をPC・スマホ相当で検証する。

Android 1.0.5は同じアプリID・同じ署名でversionCodeを6へ増やした上書き更新。releaseビルド・Lint・署名と配布ハッシュを検証し、実機での起動・更新・データ保持は未確認であることを区別する。

今回の確認結果：単体テスト71件、型チェック、Webビルド、Android releaseビルド・Lint、署名証明書一致・配布ハッシュ確認が完了。PC／Android相当の既存ブラウザテストも実行し、下部ナビの表示修正後に制作・保存・長文編集・履歴・スマホ操作の関連37件が成功（PCでの実タッチ専用1件は対象外）。制作画面のオフライン再読み込み、本文だけの出力、世界観や別作品を変えない役割・状態・関係の保存を確認した。
