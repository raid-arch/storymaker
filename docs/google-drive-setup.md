# Google Drive同期の初回設定

Googleアカウントのパスワードやクライアントシークレットを綴庭へ入力する必要はありません。Google CloudプロジェクトとOAuthクライアントを登録し、Google Drive APIを有効にします。少量の同期用途では有料APIや請求先の登録は不要です。Google Driveの空き容量は必要です。

## アプリ管理者の設定（一度だけ）

1. [Google Cloud Console](https://console.cloud.google.com/)でプロジェクトを作成します。
2. 「APIとサービス」から **Google Drive API** を有効にします。
3. Google Auth Platformでアプリ名、連絡先、利用対象を設定します。個人で使う間はテストユーザーに自分のGoogleアカウントを追加します。
4. データアクセスに `https://www.googleapis.com/auth/drive.appdata` を追加します。一般のDriveファイル全体を読み書きするスコープは不要です。
5. 同じプロジェクト内に、次のWeb用・Android用のOAuthクライアントを登録します。

### Web用

- アプリケーションの種類：ウェブアプリケーション
- 承認済みJavaScript生成元：`https://raid-arch.github.io`（`/storymaker/` を付けない）
- ローカル開発時のみ `http://localhost:5173` 等、実際に使う生成元も追加
- トークン用のGoogle Identity Servicesポップアップを使うため、リダイレクトURIやクライアントシークレットはアプリに設定しません。
- 発行された `…apps.googleusercontent.com` 形式の **クライアントID** を、綴庭の「設定・バックアップ → 端末間同期 → Google Drive → 初回のGoogle接続設定」に入力します。両方がWeb版なら両端末に同じIDを設定します。
- 配布ビルドの既定値にする場合は `VITE_GOOGLE_CLIENT_ID` をビルド時に設定できます。IDは公開用の識別子です。GitHub Pagesの配布ではリポジトリのActions変数 `GOOGLE_WEB_CLIENT_ID` に設定すると、次回ビルドから既定値になります。

### Android APK用

- アプリケーションの種類：Android
- パッケージ名：`jp.raidarch.tsuzuriniwa`
- 配布APKの署名証明書SHA-1：`1c:99:4b:ce:76:fb:e0:5a:9a:89:d4:2d:30:c1:70:e8:d3:e6:4b:94`
- Google Play開発者サービスがある端末を使います。上記と異なる署名でビルドしたAPKには、その署名のAndroidクライアント登録が必要です。
- Android版は端末のGoogle認証を使います。Web用IDやシークレットをAndroid画面に入力する必要はありません。
- PC側とAndroid側は、必ず **同じGoogle Cloudプロジェクト** に登録します。異なるプロジェクトではアプリ専用領域を共有できません。

## 各端末で接続する

1. 「設定・バックアップ → 端末間同期」の同期サービスを **Google Drive** にします。
2. 「Googleに接続して同期」を押し、PC・スマホで同じGoogleアカウントを選びます。
3. 初回は、使いたいデータがある端末で「この端末の内容をGoogle Driveに保存」を選びます。
4. もう一方の端末で接続し、「Google Driveの内容をこの端末で使う」を選びます。接続だけでデータが上書きされることはありません。
5. 端末を切り替える前に「Google Driveと同期済み」を確認します。ブラウザ版はページの再起動時や認証の有効期限が切れた際に、接続ボタンを押して再認証が必要です。認証中は編集後・復帰時・約1分おきに自動確認します。Androidは許可を再取得できる場合は自動で継続し、再同意が必要なら接続ボタンを案内します。

## データと競合

- 同期データはGoogle Driveの非公開アプリ専用領域（appDataFolder）に保存します。通常のDrive一覧には表示されません。一般ファイルへのアクセスや共有リンクの作成は行いません。
- 作品JSONに認証トークンを含めず、トークンをIndexedDBやlocalStorageにも保存しません。アカウント識別子・メールアドレス・同期の基準情報は端末内の接続設定にのみ保存します。
- 画像込みで10MBまでです。オフライン時は端末に保存し、接続後に確認します。Drive容量が足りない場合、クラウド保存は停止し、端末の編集内容を保持します。
- 両端末で別々に変更したときは自動統合・上書きを止め、使う内容を選択します。確認画面での置き換え前に保護コピーを端末内に保存し、設定からJSONで書き出せます。
- 接続解除や同期サービスの切り替えで端末やDriveの作品を削除しません。Googleアカウント自体の連携許可を取り消す場合はGoogleアカウントのサードパーティ接続設定で行います。
- Google側の登録・権限・更新識別子を確認できない場合、安全のため同期を停止します。初回を複数端末から同時に作成して重複ファイルができた場合も停止します。まずJSONを保管し、必要ならDriveの「設定 → アプリの管理」からアプリデータを整理して一方の端末から作り直します。

Google側の設定を完了した実アカウントでの認証・Drive読み書きは、設定後に実機で確認してください。
