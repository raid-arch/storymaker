# ストーリーと世界観資料（Android 1.0.4）

## 使い方

「世界観ライブラリ」で、人物・国家・宗教・魔法・歴史などの事前情報を作成する。「ストーリー管理」で作品を作成し、作品の設定画面にある「参照する世界観」で使用する資料を選ぶ。一つの資料を複数のストーリーから参照でき、一つのストーリーで複数の資料も参照できる。世界観から「この世界観を使うストーリーを作成」も使える。

ストーリーには、参照する資料の設定と作品専用の設定が一緒に表示される。保存先を一覧・詳細に表示する。資料の編集は参照する全作品に反映される。作品専用の設定は別の作品に混ざらない。世界観とストーリーは親子関係ではない。作品内の章・シーンの構成は既存のプロットボードで行う。

参照を外すと人物関係が成立しなくなる場合は操作を止める。先に該当する関係を整理する。設定同士の任意リンクと全文検索は従来どおり全データを対象にするため、参照外の設定へのリンクや検索は可能。

## 年表と描く順番

- 「年代順の年表」：数値の年代、月、日の順で比較。紀元前にあたる負数、0年、年代未定を扱える。暦名や日付の説明は自由に記述でき、月数の上限は固定しない。数字は同一の共通暦に揃える必要があり、別の暦の自動変換はしない。
- 資料側／作品側の絞り込み、対象人物・国家、設定状態、年代未定、年の範囲で表示を絞れる。新しい出来事から表示しても、年代未定は最後の独立した区分に置く。範囲を指定した場合は未定の出来事を除外すると明記する。
- 「ストーリーで描く順番」：作品専用の出来事と、資料から「このストーリーに使う」で選んだ事件を並べる。「前へ／後へ」で保存する。元の年代や資料の順番、ほかの作品の描く順番には影響しない。
- 描く順番は事件単位の構成。既存のプロットボードの章・シーンとは独立している。

## データの互換性

保存のversionは1、IndexedDBのストアは従来どおり。Projectに省略可能な `workspaceKind`（story/world）、`worldIds`（参照先）、`eventOrder`（描く事件の順序）を追加し、従来の `parentId` を読める状態に保つ。旧バックアップには新しい必須項目を要求しない。バックアップ・同期・履歴復元も参照を維持する。

読み込み時に、既存の親・祖先のIDを参照先に引き継いでparentIdを空にする。元が「世界観」型なら世界観ライブラリ、それ以外はストーリーに分類する。以前のシリーズ・作品を共有元にしていた場合は、そのIDを「以前の共有元」として選択欄に残す。設定の複製・削除・ID変更はしない。移行前の親子関係を含む元データは、最初の読み込み時に同じ端末のIndexedDBへ保護コピーを一度だけ保存する。

世界観を削除しても、参照するストーリーは削除しない。削除した資料への参照・設定リンク・人物関係・描く順番の参照を除去する。削除前に確認し、取り消しできる。共有元の資料自体の設定は削除されるので、必要に応じてJSONバックアップを保存する。新しい参照を含むバックアップを使う端末は、両方ともこの版以降に更新する。

Androidは既存と同じアプリIDと署名でversionCodeを5に増やした上書き更新。ビルド・Lint・署名確認と実機動作の確認は区別し、今回の実機での起動・更新・データ保持は未確認。
