# 一つの世界観で複数の物語を作る

1. プロジェクトを作成し、種類を「世界観」にする（種類は自由入力）。
2. 国家・人物・共通の歴史などをこのプロジェクトに登録する。
3. 「この世界観に物語・章を追加」で子の作品を作成する。既存作品は編集画面の「上位プロジェクト」で世界観を選ぶ。
4. 子の作品では、自分の設定と上位の共通設定が一緒に表示される。兄弟の作品の専用設定は混ざらない。
5. 作品内で作った設定を共通化する場合、設定の編集画面の「設定の保存先（共有範囲）」で上位を選ぶ。

共通設定の編集は、同じ設定を見るすべての作品に反映される。共通人物を開いても、元の物語の閲覧位置を維持する。共通人物と作品の専用人物を結ぶ関係も保存・復元できる。関連する人物関係が共有範囲を外れるような上位プロジェクトの変更は止め、整理を案内する。

家系図と自動配置、年表、伏線一覧、用語・画像資料・地図・テンプレート・認識・時代設定・履歴は上位を参照する。プロットボードと公開用出力は作品ごとに分離する。全文検索は従来どおり全プロジェクトを対象とするため、他作品の検索結果も表示される。Markdownは選んだ作品・その下の章と上位の共通設定を含み、兄弟作品は含まない。

## 互換性

データのversionは1のまま。既存のparentIdを使い、データの複製・削除・初期化や新しい必須フィールドの追加はしない。以前から階層を作っていた場合は、更新後に上位の設定も表示される。独立プロジェクトの表示範囲は変わらない。JSONバックアップの人物関係検証を、所属作品および上位の共通人物に対応させた。共有人物を含む新しいバックアップは旧版の厳しい検証では読めないため、復元先・同期先も更新すること。

## Android 1.0.3

同じ署名・同じアプリIDでversionCodeを4に増やした上書き更新。データを消す処理は含まない。手動更新確認時は、更新が見つかったらモーダル内の「APKを更新」から進める。Androidのインストール許可と最後の更新確認は引き続き必要。APKビルド・署名検証と実機での動作確認は区別する。

検証：単体テスト65件、TypeScript型チェック、Webビルド、Android releaseビルド・Lintが通過。世界観と兄弟作品の分離・共通設定の編集と再読み込み・共通人物を含むバックアップ検証・Markdownの共有範囲を確認した。APKは1.0.2と同じ署名証明書であること、配布メタデータのSHA-256一致、配布APKやService WorkerをAPK内に混入させていないことを確認した。実機での今回のAPK起動・更新操作は未確認。
