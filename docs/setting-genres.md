# 設定をジャンルから選ぶ（1.0.8）

世界観の制作画面、世界観データベース、ストーリーの「舞台・設定資料」にジャンル選択を追加した。多数のカテゴリを横並びにせず、件数付きの選択欄から必要な設定を表示する。検索と併用でき、絞り込み解除で全件に戻る。

世界観の制作画面では、ジャンル選択に合わせて新規作成の種類・カテゴリも切り替わる。人物／歴史・出来事／秘密・謎は既存の kind、国・都市・村・病気などは既存の category を使用する。「ジャンルを追加」から自由な分類を作れる。同名の場合は重複登録しない。新規作成後は作った設定のジャンルを表示し、古い検索語を解除する。

Data.categories と Entry.kind / category を利用し、保存スキーマの変更やデータ移行は不要。分類の選択だけで設定本文や参照を変更しない。追加した分類はJSONバックアップと既存の同期に含まれる。ストーリー内の参照資料では共有元のカテゴリをそのまま使う。

確認：単体テスト74件、型チェック、PC・Pixel 7相当で分類／検索の併用・独自ジャンル追加・設定作成・再読み込み・参照資料の分類・既存カテゴリ／症候群操作を検証。APKはリリースビルド・lint・署名を確認し、実機の表示は未確認。
