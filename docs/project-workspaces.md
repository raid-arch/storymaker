# 開始画面とプロジェクト編集

新規起動時は開始画面を表示します。「プロジェクトを開く」から世界観と物語を選択します。「設定・バックアップ → 基本設定」で、開始画面から始めるか前回のプロジェクトを再開するかを端末ごとに指定できます。

世界観は親プロジェクトです。時間・暦、国、街、病気、人物、世界の法則などを共通設定として作成します。物語をその世界観の下に作成すると、共通設定を参照できます。物語では構成、章、シーン、本文、人物の役割や場面ごとの状態を編集します。共通設定の本文を編集した場合は親に反映され、同じ親を使う物語にも反映されます。

PCでは左にプロジェクトと編集機能、中央に制作画面、右に親の資料や子の物語を表示します。スマホではプロジェクトを開いて作業を選び、一つの編集画面に集中できます。下部の「関連資料」で親・子の情報を開きます。従来の年表・家系図・検証などは「その他」の補助ツールから利用できます。

既存の collectionId と worldIds を継続利用し、設定本文を複製することなく親を参照します。シリーズの祖先にある世界観も継承し、兄弟の物語専用設定は共有しません。親を変更する際には子の参照範囲も更新し、既存の人物関係が参照範囲外になる場合は変更を拒否します。端末内の既存データは初期化しません。バックアップ、選択プロジェクトの入出力、同期は設定画面の専用タブにあります。

## 長押しとゴミ箱（1.2.1）

プロジェクト選択画面では、世界観・物語のカードを長押し、PCでは右クリックして操作メニューを開けます。「…」からも同じ操作ができます。編集は名前・説明などを変更し、削除は確認後にゴミ箱へ移します。親の世界観を削除しても、参照している物語自体は残ります。

開始画面・プロジェクト選択画面の下部、または「設定 → 基本設定」からゴミ箱を開けます。設定の削除もゴミ箱に入り、再起動後も保持され、全データのJSONバックアップや同期に含まれます。復元では関連リンク・人物関係・本文・過去の版なども戻し、削除後に編集した別データは維持します。関連データの変更により整合性を保てない場合は、データを変更せず復元を止めます。

「完全削除」は再確認後にゴミ箱の記録を削除します。直前の操作の取り消し用データも破棄し、アプリのゴミ箱や変更履歴からは戻せなくなります。以前書き出したバックアップファイル自体は変更しません。自動でゴミ箱を空にする処理はありません。

## スマホの一覧と時間軸グラフ（1.2.1）

「設定 → 見た目 → スマホの編集画面」で「一覧から専用画面へ」または「一覧と詳細を同じ画面に」を選べます。人物・参照資料・シーン・世界観の制作画面に適用し、PCでは左右並列のままです。専用画面の「一覧へ戻る」で選び直しても検索条件や入力内容は維持されます。

物語の「シーンの時間軸」はグラフを初期表示します。世界の出来事と物語のシーンを、共通年ごとに左右へ並べます。年の間隔は均等で、実際の年数の長さを表す縮尺ではありません。年代未定は最後に分離し、自由記述の「翌朝」などを数値に推測変換しません。章・人物で絞り込め、カードから元の出来事やシーンを開けます。「一覧」へ切り替えると従来の章順・共通年順の表示も使えます。
