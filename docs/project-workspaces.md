# 開始画面とプロジェクト編集

新規起動時は開始画面を表示します。「プロジェクトを開く」から世界観と物語を選択します。「設定・バックアップ → 基本設定」で、開始画面から始めるか前回のプロジェクトを再開するかを端末ごとに指定できます。

世界観は親プロジェクトです。時間・暦、国、街、病気、人物、世界の法則などを共通設定として作成します。物語をその世界観の下に作成すると、共通設定を参照できます。物語では構成、章、シーン、本文、人物の役割や場面ごとの状態を編集します。共通設定の本文を編集した場合は親に反映され、同じ親を使う物語にも反映されます。

PCでは左にプロジェクトと編集機能、中央に制作画面、右に親の資料や子の物語を表示します。スマホではプロジェクトを開いて作業を選び、一つの編集画面に集中できます。下部の「関連資料」で親・子の情報を開きます。従来の年表・家系図・検証などは「その他」の補助ツールから利用できます。

既存の collectionId と worldIds を継続利用し、設定本文を複製することなく親を参照します。シリーズの祖先にある世界観も継承し、兄弟の物語専用設定は共有しません。親を変更する際には子の参照範囲も更新し、既存の人物関係が参照範囲外になる場合は変更を拒否します。端末内の既存データは初期化しません。バックアップ、選択プロジェクトの入出力、同期は設定画面の専用タブにあります。
