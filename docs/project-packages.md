# 世界観・ストーリー単位の追加と書き出し（1.0.9）

設定・バックアップの「世界観・ストーリー単位の受け渡し」を使用する。

- 「世界観・ストーリーをJSONから追加」でファイルを選択し、対象の名前と件数を確認して「既存データを残して追加」を押す。
- 既存作品・表示設定・バックアップ日時は保持する。名前が同じ場合も別コピーとして追加する。同一作品の上書き・自動統合は行わない。
- 選択した世界観・シリーズ内の作品と、参照やツリーの所属に必要な保存先を含めて書き出す。最終的に含まれる名前を画面で確認できる。作品だけの選択では、その作品の依存先を含め、ほかの兄弟作品は含めない。
- 従来の全データバックアップは別の操作として維持する。

部分ファイル形式は `{ "format": "tsuzuriniwa-project-package", "version": 1, "data": ... }`。部分ファイルを復元ボタンから選んでも、自動で追加モードにする。従来の全データJSONも追加ボタンからなら別コピーとして追加可能。

プロジェクト・設定・関係・制作データのIDをすべて振り直し、世界観参照、ツリー、リンク、人物関係、画像資料、シーン、場面ごとの人物状態のキーなどを対応付ける。本文・自由項目にIDと同じ文字列があっても置換しない。選択外の作品の履歴と未使用の画像アセットは書き出さない。画面表示設定や同期認証情報も持ち出さない。

確認：単体テスト76件、型チェック、PC・Pixel 7相当ブラウザ18件。既存データ保持、ID衝突時の追加、シーン参照と人物状態、選択外の本文・履歴の除外、再読み込み、従来の全データ復元を確認。Androidはリリースビルド・lint・署名を確認（実機の画面確認は未実施）。
