# デザインのカスタマイズ（1.0.6）

ホームの「カスタマイズ」または「設定・バックアップ」から変更する。

- 見本付きの8種類：深緑の書斎、星夜のアトリエ、月影の図書館、薔薇の手帖、古書の頁、海辺の製図室、墨の作業室、白紙のアトリエ。
- プリセットは明るさ・アクセント・背景・カード・本文書体をまとめて変更する。文字サイズ、余白、一覧表示、ホームの表示順・表示項目は維持する。
- アクセント7色、背景4種類（無地・光・紙・方眼）、カード3種類（クラシック・やわらか・輪郭くっきり）を個別に調整できる。
- 外部画像・フォント・アニメーションは使わず、オフラインで利用できる。

背景・カードの設定は Appearance.background / surface の省略可能な項目として保存する。以前のJSONは無地・クラシックとして表示し、保存・復元の互換性を維持する。設定以外の作品・人物データは変更しない。表示設定の初期化でも作品は削除しない。

確認：型チェック、72件の単体テスト、PC・Pixel 7相当ブラウザで全プリセット選択、個別変更、再読み込み、表示設定の初期化、既存作品保持、制作画面の保存・オフライン再開。Androidはリリースビルド・lint・以前のAPKとの署名一致を確認（実機での画面確認は未実施）。
