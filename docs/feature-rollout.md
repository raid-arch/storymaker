# 汎用創作スタジオの追加

既存の作品データと version 1 JSON は維持し、任意の `studio` 領域を追加する。
初回利用者への作品サンプル登録は行わない。架空の作品名・一族名を仕様に組み込まない。

実装と検証の順序:

- 保存の互換性、画像の共有保存、拡張データの検証、削除時の参照整理
- 変更履歴、手動の版保存、復元、影響範囲
- 家系・年表の検証、人物の認識、時代別の設定
- 世界地図、用語辞典、プロット、画像資料
- 家系図の自動配置、設定テンプレート、公開情報だけの書き出し

各機能を単体テストまたはブラウザテストで確認し、最後に既存機能とPC・スマートフォン表示を検証する。
公開は検証済みの状態で行う。履歴や非公開の真相は公開用の出力に含めない。
