# 汎用創作スタジオの追加

## 保存の方針

既存の `Data.version: 1`、IndexedDB名・ストア・キーは変更しない。追加機能は任意の `studio.version: 1` に保存する。旧JSONに `studio` がなければそのまま読み込み、追加機能を初めて保存するときに領域を追加する。追加領域の未導入リストだけを補い、不正な形式や未対応バージョンはエラーにして現在の端末データを保護する。画像は追加領域内で重複保存を避ける。

ユーザーの作品名・一族・制度はアプリの仕様や初回データに含めない。新規プロフィールは空の状態で、ジャンル・役割・認識状態・カテゴリ・自由項目は記述して作れる。

## 実装と検証の段階

1. 保存互換性、画像の共有保存、拡張データの検証、削除時の参照整理。
2. 設定・プロジェクトの変更履歴、手動の版保存、差分比較、削除前の版と復元、直接・間接の影響候補。
3. 家系・生没年・事件の前後条件の検証、人物の認識、過去の年での既知情報、時代別の設定の閲覧。
4. 地図の下絵・地点・領土、用語辞典、章とシーンのプロット、画像資料と出典。
5. 血縁からの家系図自動配置、再利用テンプレート、公開用の文章だけのプレビューと書き出し。
6. 既存の編集・保存・削除・バックアップ・オフライン・同期・カスタマイズ・インストール導線の回帰確認。

各段階で型チェック、計算・互換性の単体テスト、PCおよびPixel 7相当のChromiumで作成・編集・再読み込みのブラウザテストを実施する。地図と家系図はCDPのタッチ入力でもドラッグを検証する。Android実機検証の代わりではない。

## 機能ごとの範囲

- 永続履歴は人物・世界観・事件・伏線・プロジェクトが対象。自動記録は変更前の版で、同一設定の30秒以内の連続編集をまとめる。残したい案は「版を保存」で明示的に記録できる。地図等の追加機能の編集は既存のメモリ上の取り消しに対応する。
- 矛盾チェックは構造化した数値・リンク・親子／養子・事件の前後条件を対象とする。本文の自然言語の意味は解析しない。長寿種・時間移動等を妨げないよう、年齢の制限は任意で、疑義は「確認候補」として示す。
- 時代表示は別に保存した案を投影する読み取り専用画面。現在の保存内容を書き換えない。案のない設定は現在の内容を基準とし、年指定時には未来の事件を除き、人物の時点年齢と関係期間を反映する。地図の領土自体の自動年代補間は行わない。
- 世界地図は地理情報システムではなく、画像の上に地点と多角形を配置する創作用エディタ。領土は頂点を置いて作成し、形全体の移動に対応する。
- 公開出力は許可リスト方式。独立して入力した公開名・公開文のみを取り出し、元設定名・真相・通説・履歴・画像・リンク・内部IDを含めない。公開モードは画面プレビューであり、認証・端末ロック・外部サイトへの投稿機能ではない。
- 追加データもJSONバックアップと既存の任意の非公開GitHub同期に含まれる。画像を含む同期の既存上限10MBは変更しない。Google Drive連携やAI APIは今回追加していない。
